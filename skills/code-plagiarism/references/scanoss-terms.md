# SCANOSS / OSSKB terms (read 2026-10-21)

Source: Software Transparency Foundation terms, https://www.softwaretransparency.org/terms (quotes are exact).

- "The OSSKB is designed for professional use only and it is not offered for end-consumer use."
- "STF may log usage information for the sole purpose of monitoring service load and for the purpose of improving the OSSKB."
- "Information provided by the OSSKB can only be used to perform software identification."
- The terms do not state whether submitted fingerprints are stored or shared. No retention period is published.

How the fingerprint tier follows from this: the skill shows the exact WFP before sending, uses the service only for
software identification (candidate origin and licence evidence for code the user already holds), and does not
republish knowledge-base data. The consent text (`DISCLOSURE` in `scripts/scanoss_backend.py`) repeats the first and
third quote.
